### Tópicos Avaliados
Os seguintes requisitos foram exigidos e avaliados no desenvolvimento desta aplicação:

*   **Tema Norteador:** Desenvolvimento de uma aplicação web para monitoramento inteligente de uma missão espacial experimental.
*   **Estrutura HTML Semântica:** Utilização correta de tags semânticas (header, main, section, article, aside, footer).
*   **Estilização Visual:** Aplicação de CSS utilizando classes, IDs, cores, bordas, espaçamentos e Box Model.
*   **Layout e Responsividade:** Organização dos elementos com Flexbox e adaptação para dispositivos móveis utilizando Media Queries.
*   **Dashboard da Missão:** Criação de área exibindo dados simulados (temperatura, energia, comunicação, status, sensores).
*   **Formulário de Cadastro:** Implementação de formulário com inputs, labels, select, textarea e botão submit.
*   **Interatividade com JavaScript:** Manipulação do DOM, eventos, alteração dinâmica de conteúdo e interação com botões.
*   **Manipulação Visual Dinâmica:** Funcionalidades para alteração de interface (ex: mudança de tema, ocultação de elementos, atualização de status).
*   **Organização do Código:** Estrutura de pastas, separação de arquivos (HTML, CSS, JS), indentação e comentários.
*   **Restrições:** Utilização exclusiva de conteúdos abordados até a Aula 12 e proibição de frameworks externos.

## Detalhes das Atividades

### Global Solution - 1º Semestre (GS1)

**Descrição da Atividade:**
Desenvolver uma plataforma web interativa, moderna, organizada e responsiva para o monitoramento de uma missão espacial fictícia. A solução deve conectar tecnologias computacionais a problemas reais da indústria espacial, permitindo o acompanhamento operacional e a interação do usuário com dados simulados, aplicando estritamente os conceitos lecionados na disciplina até a Aula 12.
